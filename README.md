# @amlplugins/hubspot-crm-companies

Native `@hubspot/api-client` SDK re-exported under the `@amlplugins` namespace.

> HubSpot CRM Companies — company properties, associations, batch CRUD, search.

## Install

```bash
npm install @amlplugins/hubspot-crm-companies
```

## Use

```ts
import { /* named exports from @hubspot/api-client */ } from "@amlplugins/hubspot-crm-companies";
// or
import sdk from "@amlplugins/hubspot-crm-companies";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
